Always get explicit "Approved" before editing files or running commands.

**Why:** Yoshi reviews before every action — he's been explicit about this pattern throughout the session.

**How to apply:** When about to edit or run something, state what you're about to do and stop. Wait for "Approved" or equivalent before proceeding.

---

Don't narrate what you just did after edits — he can read the diff.

**Why:** He said so directly in this project's CLAUDE.md style preferences.

**How to apply:** End turns with one line on what changed and what's next, nothing more.

---

Use Google Sheets for CSV review, not Numbers or Excel.

**Why:** Yoshi corrected this directly when a Numbers open command was suggested.

**How to apply:** When a CSV needs review, give the file path and say "import into Google Sheets."
